# Enterprise Intelligence Architecture Report

Date: 2026-06-24

## Objective

Asystence now has a dedicated enterprise intelligence domain that owns score generation, explainability, persistence, snapshots, and incremental recalculation.

## Authoritative Source

All new intelligence outputs originate from:

- `intelligence/engine/unifiedIntelligence.engine.js`
- `intelligence/evaluators/*`
- `intelligence/repositories/unifiedIntelligence.repository.js`
- `intelligence/analytics/unifiedDashboard.adapter.js`

Dashboards consume repository-backed intelligence through:

- `services/dashboard.service.js`
- `intelligence/intelligence.controller.js`
- `/dashboard/overview`
- `/dashboard/executive-detail`
- `/intelligence/unified/snapshot`
- `/intelligence/unified/history`

Legacy integration execution signals are routed into the same enterprise workspace evaluator. The active realtime observer queues unified recalculation, and socket health pulses read the stored `workspace_intelligence` score instead of writing or recalculating `workspace_health`.

## Evaluation Layers

User intelligence evaluates:

- Execution Reliability
- Delivery Effectiveness
- Collaboration Health
- Work Sustainability
- Professional Discipline
- Attendance Intelligence

Team intelligence evaluates:

- Team Performance Index
- Delivery Reliability Index
- Collaboration Index
- Execution Predictability
- Team Risk Index

Project intelligence evaluates:

- Delivery Health
- Velocity Health
- Scope Stability
- Dependency Risk
- Completion Confidence

Workspace intelligence evaluates:

- Workspace Health Index
- Productivity Index
- Strategic Risk Index
- Delivery Confidence Index
- Organizational Alignment Index
- Execution Reality Index

## Attendance Model

Attendance is now evaluated as an operational discipline signal. It excludes weekends, holidays, approved leave, approved partial leave, and non-working days through workspace schedule, holiday, and leave data.

Attendance is not recalculated on every sign-in or sign-off event. Per product direction, attendance intelligence is recalculated at end-of-day after `attendance_daily` aggregation completes.

## Explainability

Every generated intelligence row contains:

- `score`
- `band`
- `trend`
- `confidence`
- `strengths`
- `concerns`
- `drivers`
- `indicators`
- `risk`
- `evidence_hash`
- `calculation_version`

## Dashboard Preservation

The dashboard design system is preserved. Added charts use existing borders, spacing, typography, variables, and cards.

Dashboard chart datasets are generated by the enterprise dashboard adapter as `visualizations.charts`. React renders those chart configs and does not calculate scores or comparison datasets locally.

Department comparisons are currently backed by manager/team intelligence scopes because the existing workspace schema does not contain a department taxonomy. No synthetic department records are generated.
